# IncidentGuard AI

IncidentGuard AI is an intelligent log analysis system that helps identify errors and warnings from uploaded log files.

## Features

- Log Upload
- Error Detection
- Warning Detection
- Incident Analysis
- Web-Based Interface

## Tech Stack

- Python
- Flask
- HTML
- GitHub

## Future Scope

- AI Root Cause Analysis
- Email Notifications
- Real-Time Monitoring
- Dashboard Analytics
